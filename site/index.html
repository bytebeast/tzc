Features

No timezone math in your head.

Built for the moment you're staring at an error line at 2am. It reads whatever you copied, gets daylight saving right, and tells you when the answer might be wrong.

paste

Paste and go

Auto-detects about a dozen timestamp formats, so you rarely have to tell it anything about the input.

Z +02:00 PST IST

UTC and offset aware

Offsets and named abbreviations are understood, with a warning when one is ambiguous (CST, IST, BST) or wrong for the date.

DST

Daylight saving, done right

Naive times use your real IANA zone's rules for that date. A time skipped or repeated by a clock change is flagged and shown both ways.

1721831718123

Epoch in any resolution

Seconds, milliseconds, microseconds or nanoseconds, detected automatically.

"31 days ago"

Plain-English input

Type 31 days, 4 hours ago or in 3 hours and it resolves against now.

--to A,B --to C

Every zone at once

Repeat --to or pass a comma list. One timestamp, one line per zone, ready for the postmortem timeline.

fzf

Fuzzy zone picker

Search the full IANA list by name, abbreviation or offset (-8h). TAB to pick several.

Relative

How long ago

Every result ends with a friendly 31 days, 4 hours ago, so you know if it's the incident or last month's noise.

alias

Alias friendly

--to skips the picker, so your usual zones, or your whole team, are one short word away.

--strict

Script safe

Exits 3 when the result carries a warning, so a script never trusts a guess.

--from --day-first

Tell it what it can't know

Pick the zone for naive timestamps, and read 03/04/2026 as DD/MM instead of MM/DD.

catppuccin

Readable output

Catppuccin Mocha colors in the terminal. Auto-off when piped or when NO_COLOR is set.

stdlib

One file, zero deps

A single Python script on the standard library. fzf is optional, with a plain prompt fallback.

Formats

Whatever you copied, it reads.

Naive timestamps are read in your local zone unless you pass --from. Fractional seconds are kept, and syslog lines with no year get the most recent year that isn't in the future.

Install

One file. Drop it on your PATH.

Then wrap the zones you live in with an alias or two, so a conversion is one word away.

install

# standard library only; fzf powers the picker
curl -o tzc https://raw.githubusercontent.com/bytebeast/tzc/main/tzc
chmod +x tzc
mv tzc ~/.local/bin/
brew install fzf

aliases

# ~/.zshrc or ~/.bashrc
alias tzblr='tzc --to Asia/Kolkata'
alias tzteam='tzc --to America/Los_Angeles,Europe/London,Asia/Kolkata'

clipboard

# convert whatever you just copied (macOS)
tzall() { tzc "$(pbpaste)" --to America/Los_Angeles,Asia/Kolkata; }
